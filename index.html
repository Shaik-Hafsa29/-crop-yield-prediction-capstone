Crop Yield Prediction

A Data-Driven Analysis of Agricultural Climate Resilience

View Source Code on GitHub

Project Overview

Climate change and agricultural practices drastically affect crop output. This Capstone project explores the FAO/World Bank dataset to analyze how Rainfall, Temperature, and Pesticide/Fertilizer use impact crop yields—with a specific focus on regional crops like Potatoes in India.

Methodology

The core pipeline of this data science project includes:

  • Data Acquisition: Programmatic fetching using kagglehub.
  • Data Cleaning: Imputation of missing values and standardization of units (hg/ha, mm, °C).
  • Exploratory Data Analysis: Heatmaps and scatterplots to map non-linear relationships.
  • Regression Modeling: Multiple Linear Regression implemented via scikit-learn.
